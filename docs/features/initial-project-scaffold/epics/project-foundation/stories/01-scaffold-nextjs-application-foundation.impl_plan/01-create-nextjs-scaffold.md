# Step: Create the Next.js scaffold

## Goal

Establish the baseline Next.js application using pnpm, App Router, TypeScript, `src/`, Tailwind, and ESLint while preserving generated defaults where reasonable.

## Scope

- Generate or add the standard Next.js project foundation in the repository root with pnpm as the package manager.
- Select App Router, TypeScript, `src/` directory, Tailwind CSS, and ESLint options.
- Keep generated configuration simple and close to current Next.js defaults.
- Do not add database, Drizzle, Docker, README completion, product modules, auth, AI, or Adventure behavior in this step.

## Files

- `package.json`
- `pnpm-lock.yaml`
- `next.config.*`
- `tsconfig.json`
- `eslint.config.*`
- `postcss.config.*`
- `src/app/layout.tsx`
- `src/app/page.tsx`
- `src/app/globals.css`

## Done when

- The repository contains a Next.js App Router scaffold using TypeScript, `src/`, Tailwind, ESLint, and pnpm.
- Generated files remain focused on application foundation concerns only.
- No product behavior, product data model, database setup, Drizzle setup, Docker Compose file, or README rewrite has been introduced.
